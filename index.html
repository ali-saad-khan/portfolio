// 01. ABOUT ME

Backend-Focused Engineer with Practical Experience

Understanding business problems, designing backend logic, and delivering maintainable web applications.

I am a Software Engineer at Technyx in Karachi, specializing in PHP, Laravel, MySQL, and modern web application development. I enjoy building practical software that solves real business requirements rather than over-engineering simple problems.

Backend development is my core strength. I work extensively with PHP and the Laravel framework, modeling relational database schemas, engineering RESTful APIs, and implementing business logic for applications with complex user flows, subscription plans, wallets, and delivery operations.

In addition to custom web applications, I have hands-on experience maintaining enterprise WordPress installations (ACF, Elementor, Custom Post Types) and customizing Shopify e-commerce stores. I am comfortable navigating Linux server environments (Apache, Nginx, PHP-FPM, Caddy), managing deployment pipelines, and troubleshooting production bugs under pressure.

I view software development as a full lifecycle process: understanding the business requirement, planning database relationships, building clean backend and frontend code, validating data integrity, deploying securely, and debugging root causes.

// 06. PROCESS

Development Approach

A systematic 5-step methodology for turning requirements into maintainable software.

01

Understand

Analyze business requirements, existing legacy systems, data flows, and constraints before writing code.

02

Design

Plan relational database schemas, API payload structures, model relationships, and system architecture.

03

Build

Implement clean, readable, and maintainable backend logic and responsive frontend components.

04

Test

Validate edge cases, database constraints, input data sanitization, and end-to-end user workflows.

05

Deploy & Maintain

Deploy to production environments, configure web servers, monitor logs, and debug root causes.

"Good software isn't just code that works. It's code that remains understandable, testable and maintainable when the requirements change."
✓ Keep business logic explicit and centralized.
✓ Protect data integrity with database constraints & transactions.
✓ Validate all user and API inputs strictly.
✓ Handle boundary cases and unexpected failures gracefully.
✓ Write clean code that another developer can read.
✓ Understand the database execution plan, not just the ORM syntax.
✓ Debug the root cause of issues rather than patching symptoms.
✓ Keep production systems reliable, fast, and secure.
