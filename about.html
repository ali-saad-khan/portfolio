Who I am

I'm a Software Engineer at Technyx in Karachi, specializing in PHP, Laravel, MySQL and modern web application development. I enjoy building practical software that solves real business requirements rather than over-engineering simple problems.

Backend development is my core strength. I work extensively with PHP and the Laravel framework, modeling relational database schemas, engineering RESTful APIs and implementing business logic for applications with complex user flows, subscription plans, wallets and delivery operations.

What I work on day to day

Beyond custom web applications, I maintain enterprise WordPress installations (ACF, Elementor, Custom Post Types) and customize Shopify stores. I'm comfortable on Linux servers (Apache, Nginx, PHP-FPM, Caddy), managing deployments and troubleshooting production bugs under pressure.

How I think about software

I treat development as a full lifecycle: understand the business requirement, plan the database relationships, build clean backend and frontend code, validate data integrity, deploy securely and debug root causes instead of symptoms.

"Good software isn't just code that works. It's code that remains understandable, testable and maintainable when the requirements change."
  • Keep business logic explicit and centralized.
  • Protect data integrity with database constraints and transactions.
  • Validate all user and API inputs strictly.
  • Handle boundary cases and unexpected failures gracefully.
  • Understand the database execution plan, not just the ORM syntax.
  • Keep production systems reliable, fast and secure.
