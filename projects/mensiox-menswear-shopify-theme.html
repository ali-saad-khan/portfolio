Mensiox: Animated Menswear Storefront on Shopify

A modern, soft-pastel menswear store built for a client pitch: a floating pill header, a hero slider with word-by-word headline reveals, a pinned headline that changes as product cards drift past, a cycling word list, stacking layered cards with spinning stickers, wishlist hearts and a cart drawer with a free-shipping meter. Brand, products and artwork are original demo content.

The challenge

The brief was a menswear store with the polish of an award-style storefront: bold type, rounded surfaces and motion that guides the shopper down the page, without paying for a premium theme or installing apps.

Everything had to stay editable in the theme editor, respect reduced-motion settings and keep the purchase path (quick add, cart drawer, free-shipping nudge) one tap away.

How I approached it

  1. 01

    Scroll-driven storytelling

    A pinned headline swaps text and animates a marker highlight as the visitor scrolls, while product cards drift past at different speeds. Scroll progress is read once per frame and the cards use transforms only.

  2. 02

    Stacked layered cards

    Full-width cards use sticky positioning so each one slides over the last. A small script scales and dims the card underneath, and spinning circular stickers float on top.

  3. 03

    A cycling word list

    A pastel panel cycles through words (Work, Weekend, Travel, Dinner) with a wavy underline and a thumbnail pill. Hovering pins a word and pauses the loop.

  4. 04

    Cards that sell

    Product cards crossfade to a second image, show colour swatches mapped from the variant option, slide up size buttons that add straight to the cart drawer and keep a local wishlist heart.

  5. 05

    Conversion touches

    The cart drawer shows a free-shipping progress bar, a newsletter popup appears after a delay and remembers that it was dismissed, and an automatic discount powers the 'buy 3 shirts, save 15%' offer.

  6. 06

    Original art, generated

    Garment and scene artwork is drawn procedurally in Python (Pillow), so there are no licensing issues and the set regenerates from a script. The catalogue is seeded through an idempotent Admin GraphQL script.

Deliberate trade-offs

  • The imagery is illustrated, not photographed. A real launch would swap in product photography.
  • The bundle discount percentage shown on the page must be kept in sync with the store discount.
  • It is a demo brand with sample content, not client work.

What I built

  • Designed and wrote 10 custom sections, the product card snippet and the shared stylesheet and script.
  • Built the scroll-driven headline, layered cards, word list, marquees, hero slider, popup and cart free-shipping bar.
  • Wrote the procedural artwork engine and the Admin API seeding script, and set up the automatic bundle discount.
Original showcase store built with demo content. The storefront runs on a Shopify development store.

What this project demonstrates

  • Award-style scroll motion built from plain Liquid, CSS and JavaScript
  • Reduced-motion and accessibility awareness
  • Conversion-focused storefront features without apps
