Pith: Playful Zero-Proof Drinks Storefront on Shopify

A bright, sticker-style brand store with personality: a peel-to-enter splash, a canvas slice-the-fruit mini game, reviews as a group chat, a drag-to-scroll photo strip, a merch drop grid and a small citrus mascot that rides a zig-zag line down the page, reacting to the content as it passes.

The challenge

Playful brands live or die on delight. The challenge was to add real interactivity (a game, an animated chat, a mascot) without hurting performance, accessibility or the purchase path.

Everything had to stay editable in the theme editor and degrade gracefully when motion is reduced.

How I approached it

  1. 01

    A mascot tied to scroll

    Scroll progress maps to a point on a zig-zag SVG path sampled once into an array, so each frame is cheap. The mascot walks down, climbs back up, waves when you pause and trips small reactions in nearby elements.

  2. 02

    A game in a canvas

    The slice game uses pointer events, swept-segment collision so fast swipes still connect, a timer, rarity-style ranks and a result card.

  3. 03

    Reviews as a chat

    Messages appear on scroll with a typing indicator, so social proof reads like a conversation instead of a carousel.

  4. 04

    Accessible by default

    The mascot and game are decorative or progressively enhanced, controls are real buttons, and reduced-motion users get a static page with every product still one click away.

  5. 05

    Same system, new skin

    The shared page system is re-skinned with rounded stickers, thick outlines and offset shadows, which shows how quickly a brand can be turned around.

Deliberate trade-offs

  • The giveaway and swap guarantee are demo copy. A real brand would wire the signup to an email platform.
  • It is a demo brand with sample content, not client work.

What I built

  • Wrote 10 sections and the scroll-driven mascot (Pip) with pose switching, wake effects and element reactions.
  • Built the slice game, chat reviews, drag strip, merch drop grid, retired-flavours lookbook and giveaway signup.
  • Drew all bottle, can, fruit and merch artwork procedurally and seeded the store through the Admin API.
Original showcase store built with demo content. The live storefront runs on a Shopify development store and is password protected.

What this project demonstrates

  • Delightful, interactive storefront experiences built from scratch
  • Canvas, SVG and scroll animation done with performance in mind
  • Reduced-motion and keyboard consideration in playful UI
