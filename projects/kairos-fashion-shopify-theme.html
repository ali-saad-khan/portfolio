KAIROS: Editorial Fashion Storefront on Shopify

A showcase store I built from scratch to show what a bespoke Shopify theme can look like: a dark, editorial fashion brand with shop-the-look pins, a countdown drop, count-up stats and product cards that quick-add straight into the cart drawer. Brand, products and artwork are all original demo content.

The challenge

A fashion pitch needs more than a re-skinned template. The storefront has to feel like a brand: confident type, rich imagery, motion that sells the product and a purchase path that never gets in the way.

The constraint was to do it on Online Store 2.0 with no apps and no front-end framework, so every interaction is plain Liquid, CSS and a few hundred lines of vanilla JavaScript that a merchant's developer can maintain.

How I approached it

  1. 01

    Design system first

    A single stylesheet carries the palette, type scale and motion tokens. Sections only compose those tokens, so a colour or font change in theme settings ripples through every custom section.

  2. 02

    Product cards that sell

    A kx-product-card snippet swaps to the second image on hover, shows colour swatches mapped from the variant option, and exposes size buttons that add to the cart through the AJAX Cart API and refresh Dawn's cart drawer.

  3. 03

    Shop the look

    A section lays product pins over an editorial flat-lay. Each pin is a block with a product picker and X/Y position, and clicking a pin highlights the matching product in the list.

  4. 04

    Everything is editable

    Every section is configurable in the theme editor: blocks, pickers, colour schemes and copy. The page can be rearranged without touching code.

  5. 05

    Original art, generated

    The product and campaign imagery is drawn procedurally in Python (Pillow): garment cutouts, grain, shadows and backdrops. There are no licensing issues and the whole set regenerates from a script.

  6. 06

    Seeded through the Admin API

    Products, variants, colour-linked media, collections, menus, pages and a journal are created by an idempotent script over the Admin GraphQL API, so the store can be rebuilt from scratch.

Deliberate trade-offs

  • Imagery is generated illustration, not photography. It keeps the showcase free of licensing issues; a client build would swap in their own photography through the same image settings.
  • It is a demo store with sample products and copy, not a client launch.

What I built

  • Designed and wrote 13 custom sections, 2 snippets and the shared stylesheet and script.
  • Built hover-swap cards with size quick-add wired into the cart drawer.
  • Built a shop-the-look section with hotspot pins, a drop countdown, count-up stats and a sticky add-to-cart bar.
  • Wrote the procedural illustration engine and the idempotent Admin API seeding scripts.
  • Shipped the theme with Shopify CLI and checked it with theme-check.
Original showcase store built with demo content. The live storefront runs on a Shopify development store and is password protected.

What this project demonstrates

  • Custom Shopify theme development beyond the theme editor
  • Performance-minded vanilla JavaScript, no app bloat
  • Admin API automation and repeatable store setup
  • Design sense as well as engineering
