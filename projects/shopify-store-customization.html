Shopify E-commerce Customization

Theme-level development for a high-traffic production Shopify store: custom Liquid templates and sections, a bundle selector, and a lightweight cart drawer built on Shopify's AJAX Cart API.

The challenge

The store needed custom product bundle selectors and a cart drawer that behaved the way the business wanted, plus better mobile performance, without slowing down Liquid render time or piling on third-party apps.

How I approached it

  1. 01

    Vanilla JavaScript over app bloat

    The cart drawer and bundle logic talk directly to Shopify's AJAX Cart endpoints, which keeps the storefront light compared with stacking apps.

  2. 02

    Liquid sections with clean schemas

    Custom section files and schema settings let the team edit content in the theme editor without touching code.

  3. 03

    Responsive refactor

    Stylesheets were refactored with CSS Grid and Flexbox, fixing layout bugs across browsers and improving mobile load.

  4. 04

    Third-party widgets without the cost

    Analytics and review widgets were integrated carefully so they didn't compromise page speed.

What I built

  • Customized Liquid templates, section files and snippet components.
  • Implemented a lightweight dynamic cart drawer using vanilla JS and Shopify's cart endpoints.
  • Optimized mobile layout responsiveness and resolved cross-browser CSS issues.
  • Integrated third-party analytics and review widgets without hurting page performance.
This is private production work at Technyx for a live store, so the code isn't public.

What this project demonstrates

  • Shopify theme work beyond the theme editor
  • Performance-minded frontend JavaScript
  • Shipping changes on a store that's taking orders
