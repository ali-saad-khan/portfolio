How they are built

  • Online Store 2.0 JSON templates with schema-driven sections, so everything is editable in the theme editor.
  • Vanilla JavaScript and the AJAX Cart API instead of apps, including multi-item cart builders and quick-add.
  • Products, variants, collections, menus and content created by repeatable Admin GraphQL scripts.
  • Original artwork generated procedurally in Python, so there are no licensing issues.
  • Checked with theme-check and deployed with Shopify CLI.
These are original demo brands with sample content, not client work. The storefronts run on Shopify development stores and are password protected, so each case study shows the build instead of a public link. I am happy to walk through one on a call.
