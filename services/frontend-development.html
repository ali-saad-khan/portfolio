Frontend Development with React, TypeScript & Tailwind

I build the interface and the API behind it, so the two fit together. React, Next.js and TypeScript front ends that load fast, work on a phone and are usable with a keyboard.

Get a QuoteSee my work

Being full stack means fewer hand-offs. I design the data model and API, then build the screens that use them, so there is no gap between what the backend returns and what the UI needs. I work in React and Next.js with strict TypeScript, styled with Tailwind CSS and component kits such as shadcn/ui.

My <a href="/projects/pulseboard-react-dashboard">Pulseboard dashboard</a> shows the approach on a front-end-only project, and <a href="/projects/my-store-ecommerce-platform">my-store</a> shows it end to end with a Next.js storefront, admin area, database and browser tests.

What you get

  • React and Next.js (App Router) applications
  • Strict TypeScript and typed API clients
  • Tailwind CSS and shadcn/ui design systems
  • Responsive layouts and light/dark themes
  • Accessibility: keyboard, labels, ARIA and contrast
  • Component, unit and Playwright end-to-end tests

Frequently asked questions

Do you do both frontend and backend?

Yes. I build the Laravel or PHP backend and the React or Next.js frontend, or I can take just one side and work with your existing team.

Which frameworks do you use?

React and Next.js with TypeScript and Tailwind CSS for new builds. I also customize Shopify (Liquid) and WordPress themes.

Will the site be fast and accessible?

That is the default, not an extra. I use semantic markup, labelled controls and keyboard support, keep dependencies small and check layouts from phone to desktop.

Can you redesign an existing UI?

Yes. I can rebuild screens incrementally against your current API so you ship improvements without a big-bang rewrite.
