n8n Workflow Automation & AI Agents

I build n8n automations that keep working when something goes wrong: authenticated webhooks, paginated API pipelines, error alerts and retries, and AI steps with structured output.

Get a QuoteSee my work

I completed four n8n Academy certificates in October 2026 (Quickstart, Essentials, Integrations and AI, Testing and Best Practices) and built a set of importable workflows to put the patterns into practice. They run on a self-hosted n8n with local models through Ollama.

You can read and download them in the <a href="/projects/n8n-automation-showcase">n8n automation showcase</a>. Because I am a full stack developer, I can also build the Laravel or Next.js side that your workflows call, so the automation and the application fit together.

What you get

  • Webhook intake with authentication, validation and proper responses
  • API pagination, merging and reporting
  • Error workflows, alerts and retries with backoff
  • AI classification with structured output
  • AI agents with memory and tools
  • Self-hosted n8n and local models with Ollama

Frequently asked questions

Have you done this for clients?

My n8n work so far is training and showcase projects: four n8n Academy certificates and six importable example workflows you can inspect. I am open about that, and I apply the same engineering habits (validation, error handling, tests) as in my code projects.

Can you automate our existing tools?

Yes, anything with an API or webhooks. I start with the process, then build, test and document the workflow so your team can maintain it.

Do you use AI agents?

Where they help: classification, summarising and tool-using agents, with structured output and an error branch so a bad model response does not break the flow.

Can you self-host n8n?

Yes. I run n8n self-hosted with Docker and local models through Ollama, which keeps data in your environment.
