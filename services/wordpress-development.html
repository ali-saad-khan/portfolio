WordPress Developer: Custom Themes & ACF

I build and restructure WordPress sites so editors get a clean content model and visitors get fast pages.

Get a QuoteSee my work

WordPress gets slow and fragile when content lives in hardcoded blocks and every feature is another plugin. I model content with custom post types, taxonomies and ACF field groups, keep templates light, and replace plugin bloat with small custom code where it's safer.

I've restructured an enterprise WordPress site with 800+ pages, including multilingual content, while preserving permalinks so SEO wasn't disrupted. I also tune the database (autoloaded options, transients) to bring TTFB down.

What you get

  • Custom themes and templates
  • ACF Pro field groups and custom post types
  • Elementor customization
  • Large-site restructuring and content migration
  • Performance and database cleanup
  • WooCommerce setups

Frequently asked questions

Can you redesign or restructure an existing WordPress site?

Yes. I start by mapping the existing content, then move it into a maintainable structure with a migration that keeps URLs intact.

Will restructuring hurt my SEO?

Not if it's planned. I preserve permalink structures and handle redirects so existing rankings aren't disrupted.

Do you work with Elementor?

Yes, alongside ACF and custom PHP. I use Elementor where it helps editors and custom code where it keeps the site fast.

Can you speed up a slow WordPress site?

Usually. Common wins are database autoload cleanup, removing plugin bloat, and fixing slow queries and caching.
